About this project

This is an academic Django project. There is no support team, no office, and no real banking service.

  • Built as a final-year coursework project. Nothing here is connected to a payment network.
  • Messages sent through this form are stored in the project's local SQLite database and shown in its admin. They are not emailed anywhere — no mail server is configured.
  • No office address, and no public repository URL yet. The source runs locally and is available on request.
